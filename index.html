03 / PROJECTS

Things I keep making more difficult on purpose.

Four ongoing systems. Each one started as a smaller idea and grew into an architecture problem.

#1 ANALYZE

SoftwareForge

A desktop developer workspace for understanding repositories through visual structure, local AI, sandboxed analysis, interactive canvas flows and build-oriented tooling.

#2 SEARCH

Axiom

A custom search engine and security-browser direction built around SearXNG, a focused frontend, privacy-aware infrastructure and agent-driven research.

#3 AUTOMATE

Udaan

A real-time airfare intelligence pipeline for CPI augmentation: automated collection, normalized fare components, time-series storage, index math and an explorable public-facing dashboard.

#4 RESEARCH

QuantForge

An agent-orchestrated quantitative research engine with deterministic math, experiment memory, constrained alpha generation and robustness checks.

#5 EXPLORE

Research systems

Browser automation, scraping recipes, structured retrieval, vector memory, local models and multi-step agents used as building blocks rather than the product itself.

#6 ISOLATE

Security first

Untrusted repositories, hardened containers, network-off-by-default workflows, explicit permissions and a clear distinction between convenience isolation and real security boundaries.

I like making difficult things.

I’m Gokul Prasath. I’m interested in the point where a project stops being “just an app” and starts becoming a system.

That usually means some combination of UI, orchestration, local models, storage, sandboxing, data processing, browser automation, and a lot of iteration.

I’m currently studying at Lovely Professional University and use coursework as an excuse to build things much larger than the minimum requirement.
